# Inercept

Inercept is a concept-stage active rotational-attenuation architecture for wearable protective equipment using control-moment gyroscope (CMG) counter-torque.

## Repository status

This repository contains public-facing investor/concept material. The engineering concept remains **prototype-stage**. Modeled performance targets are not equivalent to experimentally validated helmet performance, injury-risk reduction, regulatory compliance, or clinical safety.

> **IP note:** This repository is currently public. Do not commit non-public invention disclosures, unpublished claim language, CAD, source design files, proprietary control logic, counsel work product, or other confidential IP here.

## Evidence policy

Public-facing claims should be labeled as one of:

- **Externally supported:** supported by public literature, standards, or company filings.
- **Model-derived:** calculated from explicitly stated assumptions.
- **Project-reported:** supplied by the project team but not independently verified.
- **Experimentally validated:** reserved for measured data with a documented test method.

The current review corrects a three-order-of-magnitude arithmetic error in the original CMG torque calculation and removes language that treated modeled attenuation as experimental data.

## Priority validation gates

1. Rotor structural feasibility and containment at target speed.
2. Gimbal actuator rate/torque feasibility under transient loading.
3. Full electrical and thermal power budget.
4. 3-axis CMG steering-law and singularity analysis.
5. Instrumented benchtop impulse testing.
6. Headform/neck testing using an applicable NOCSAE test method.
7. Independent comparison against passive baseline helmets.
8. Patentability/FTO and trademark status confirmation by counsel.
